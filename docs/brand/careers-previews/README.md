# Careers applications

Six openings: Full Stack Developer Intern, AI Intern, Rust/Ruby Intern, UI/UX Designer, Graphic Designer and Software Engineer. Each listing includes a full overview, responsibilities, skills and experience, and application guidance.

Rust/Ruby and both design roles require 2–3 years of relevant experience. The Rust/Ruby opening retains the requested internship title. Full stack specifies React, Next.js and backend/database capabilities; AI specifies model training, fine-tuning and evaluation.

## Referral codes

After deployment, share `/careers?ref=TEAM-01` on the website's public domain. Replace `TEAM-01` with your chosen code for each source, such as `CAMPUS-01`. Codes may contain letters, numbers, hyphens or underscores and must be at most 40 characters. Valid link codes prefill every role's application form, remain editable and are normalised to uppercase when submitted. A referral is optional.

The application email includes `referral_code`, the selected position and the referral in the subject. This is source tracking, not an invitation, access restriction or verified-referrer registry. No dashboard, reward or automatic code issuance is included.

Careers and Contact share the existing Web3Forms form ID and submission helper. Tests use mocked requests; receipt in the configured mailbox was not tested by sending a live application.
