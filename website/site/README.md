# Aletheia AI website (static)

This folder is the source of the live site: plain HTML, CSS and JS. No framework, no dependencies.

```
site/
  index.html        the homepage, written by hand
  css/  js/         styles and motion (GSAP + Lenis are vendored in assets/vendor)
  assets/           images, fonts, video, logo
  data/content.json blog posts, case studies, services, products, industries, careers, FAQs
```

Every other page is generated by `../scripts/build-site.mjs`, which also keeps the nav, menus, footer,
cookie notice and all search metadata identical across the site.

## Commands (run from `website/`)

```bash
npm run dev      # build, then serve on http://localhost:3000 with clean URLs
npm run build    # write the site into website/dist
npm test         # rebuild and check every page: titles, descriptions, links, images
```

## Changing things

- **Text on an inner page:** edit the template in `scripts/build-site.mjs` or the entry in `data/content.json`.
- **A new blog post, role or case study:** add it to `data/content.json`; the page, sitemap, feed and links follow.
- **The homepage:** edit `index.html` directly. The build swaps in the shared head, nav and footer.

## Before relying on it

- Privacy and Cookies carry a "draft" tag until they have had legal review.
- Google Analytics loads only after a visitor accepts the cookie notice.
- The six service demos on the homepage are illustrations with made-up numbers.
- `assets/art` is "The Uncovering", an AI-generated still-life series; it is brand art, not staff or client work.
